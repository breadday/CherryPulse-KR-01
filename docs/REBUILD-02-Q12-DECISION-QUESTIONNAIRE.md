# Q12 매수 패턴 결정 질문지

- 작성일: 2026-10-11
- 근거: `docs/REBUILD-02-OPEN-QUESTIONS.md` Q12, `docs/CherryPulse-KR-01-Development-Direction.md` 6절, `docs/NEXT-DEVELOPMENT-PLAN.md` D01·D05, `docs/D02-BOARD-PROGRESS.md` 218줄(D02 남은 완료 조건)
- 용도: 매수 패턴 화면·계약을 만들기 전에 사용자가 결정해야 할 값을 모으는 질문지다. 이 파일은 명세가 아니며, 값을 채우기 전에는 매수 폼·매수 실행을 만들지 않는다.

## 차단 정책

- 정해지지 않은 값을 코드 기본값으로 만들지 않는다. 모든 미기입 항목은 매수 패턴 폼·계약·가상 실행의 차단 사유로 남는다.
- 이 질문지에 답하는 것은 주문 실행 허가가 아니다. 실제/모의 주문 API 호출, 운영 DB 변경, 배포는 별도 명시적 지시 없이 수행하지 않는다.
- 손절(매도) 수치는 D01·D03에서 정한 범위(고정 가격·확인된 평균 매수가 대비 하락률, 시장가 우선)를 그대로 따른다. 여기서는 매수 값만 정한다.

## 답변 작성 방법

- 각 `답변: [미기입]`을 값으로 바꾸고, 근거(화면·문서·구두 결정 일시)를 함께 적는다.
- "나중에 정함"은 미기입으로 남긴다. 비워 둔 항목이 있으면 해당 범위의 폼·실행은 차단 상태로 둔다.
- 전부 기입되면 다음 순서로 진행한다: 매수 패턴 화면(D02) → 조건·주문 계약(D05) → 가상 시나리오 검증 → 결과 문서 기록.

## 아직 연결하지 않는 것

- D01 인증·desired/accepted/applied 적용 연결, D03 자동 시세·검증 세션, D06 키움 읽기 전용 근거, D07 실제 주문 경계는 이 질문지와 무관하게 차단 상태로 둔다.
- 물리 모바일 확인(D02 남은 조건)은 별도 체크리스트로 진행한다.
