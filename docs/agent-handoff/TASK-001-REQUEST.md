# TASK-001 요청서

상태: READY_FOR_ANALYSIS

## 목표

종목선정은 외부 시스템의 책임으로 두고, CherryPulse는 보유 포지션의 주문 실행과 위험관리 중심으로 유지한다. 특히 손절이 전략·뉴스·일봉 캐시·장중 시간 게이트·grace·trend hold 때문에 지연되거나 누락되지 않도록 구조를 분리한다.

## 반드시 검토할 범위

- RiskGuard를 전략 판단과 독립된 경로로 둘 것
- 손절 제출은 일반 자동매도 시간 제한을 우회할 것
- `on_tick`에서 위험 확인이 일봉/뉴스/캐시 조회보다 먼저 실행될 것
- 장 마감 직전 stale data와 reconnect 차단이 손절 판단을 멈추게 하지 않을 것
- 손절 감지·주문 제출·체결·수동개입 필요 상태를 재시작 후에도 복구할 수 있을 것
- 외부 종목선정 입력과 기존 내부 종목선정 로직의 책임 경계를 문서화할 것

## 안전 제약

- 실거래 모드 활성화 금지
- `.env`와 모든 비밀값 접근·출력·수정 금지
- 브로커 주문 전송 파일은 명세가 명시적으로 요구하지 않는 한 수정 금지
- 기존 동작을 바꾸기 전에 실패 경로 테스트를 먼저 설계
- 전략별 손절 기준을 임의로 바꾸지 말고 현재 설정과 정책 충돌을 명세에 기록

## 완료 기준

analyzer가 구체적인 파일·심볼·테스트 계획을 작성하고, implementer가 그 명세만 구현하며, tester와 reviewer가 실제 명령과 diff를 근거로 판정한다. PASS가 아니면 자동 publish하지 않는다.
