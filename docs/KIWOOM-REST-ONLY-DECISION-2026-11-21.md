# 키움 REST API 전용 구현 원칙 (2026-11-21)

사용자 확정: **체리플러스의 첫 증권사는 키움증권이며 반드시 키움 REST API를 사용한다.**

- 구형 키움 OpenAPI+ OCX/ActiveX, Windows COM, 32비트 Python 전용 연동은 **신규 구현에 사용하지 않는다**.
- Python은 REST 호출을 지원하는 현대적 64비트 환경을 사용한다. 구체적인 버전은 설치 가능한 라이브러리와 Windows 배포 검증 후 고정한다.
- 시세, 잔고, 주문, 체결, 실시간 알림 각각 키움 REST 공식 명세에서 지원 여부·인증·요청·응답·오류·제한을 확인한 후 구현한다. 예약주문은 키움 REST의 직접 지원 여부와 Windows 자체 예약 실행을 구분한다.
- 앱 키/시크릿/토큰은 서버 또는 PC 비밀 환경변수에만 유지하며 브라우저에 전달하지 않는다.
- UI 시안 `web/unified/index.html`은 **독립된 정적 화면**이다. 예시나 미조회 표시만 사용하고, API 인증·실제 주문·예약 등록·서버 상태 변경은 하지 않는다.
- 완료 순서: 클릭 가능한 화면 검토 → 키움 모의계좌 읽기 전용 연결 → 수동 모의주문/체결 검증 → 예약/오류복구 검증 → 실전 승인. 전략 백테스트와 타 증권사 확장은 뒤로 둔다.
