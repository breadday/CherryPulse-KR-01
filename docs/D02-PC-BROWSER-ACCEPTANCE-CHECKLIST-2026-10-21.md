# 보드 PC 브라우저 수락 체크리스트 — 2026-10-21 작성

현행 main 보드(카드 목록·상세 패널·종목별 매수·손절 연결·조건 미리보기·
초안 경고 바)를 지정 PC 브라우저에서 수락 확인하기 위한 체크리스트다.
이 확인은 소프트웨어 구현의 시각 인수이며 물리 모바일 실기기 결과가 아니고
실제 엔진·계좌·주문 상태 연동 확인도 아니다. 결과는
`docs/D02-BOARD-PROGRESS.md`에 날짜 섹션으로 기록한다.

## 실행 방법

```bat
python -m http.server 8080 --bind 127.0.0.1 --directory web
```

접속: `http://localhost:8080/` . 기존에 열어 둔 세션이 있으면
Ctrl+Shift+R(강력 새로고침) 후 확인한다. 로컬 저장(localStorage) 초기화 없이
기존 초안이 유지되는지도 확인 항목에 포함한다.

## A. 기존 6항목 재확인 — 이전 PC Chrome 6/6의 회귀 확인

1. [ ] 매수 목표가 `100001` 입력 시 "10만원 초과" 차단 문구, 초안 무변경
2. [ ] `70000` 저장 성공: 카드 추가, detail 문구 `70000원 이하 매수…` 표시
3. [ ] 손절 select에 매수 kind가 제외돼 있다
4. [ ] 토글 비활성 → 재활성 동작
5. [ ] 전체 백업 JSON에 매수 kind(예: `BUY_PRICE_AT_OR_BELOW`)가 포함된다
6. [ ] 390×844 창에서 가로 스크롤 없음(`clientWidth`·`scrollWidth` 동일)

## B. 현재 보드 화면 — 신규 확인 항목

1. [ ] 초안 모드 경고 바가 표시되고 "엔진 미연결·미적용" 문구가 실제 상태로
       오인되지 않게 명시돼 있다
2. [ ] 등록/보관 건수 표시가 실제 저장 내용과 일치한다
3. [ ] 모바일 상태 탭이 "미조회"로 명시된다. 감시·주문 상태가 생성되지 않는다
4. [ ] 종목 카드 목록이 이름·출처·연결된 패턴(이름·버전·조건)을 보여준다
5. [ ] 카드 클릭 → 오른쪽 비모달 상세 패널: 종목 수정·출처·메모·손절 패턴·
       보관·매수 패턴 연결이 열리고 저장된다
6. [ ] 매수/손절 패턴을 독립적으로 연결·해제할 수 있고 저장 후 패널이 유지된다
7. [ ] 패널 닫기 버튼과 Esc로 닫히며 포커스가 카드로 돌아온다
8. [ ] 조건 미리보기가 가상 현재가(선택적 가상 평균 매수가)로만 평가되고
       시세 조회·저장·주문을 수행하지 않는다. 실행이 일어나지 않는다는 안내가
       표시된다
9. [ ] 평균 매수가 없는 비율 손절 연결은 "평가 보류"로 표시된다
10. [ ] 기존 전역 매수 미리보기와 로그 요약이 유지된다
11. [ ] 새로고침 후 등록·연결·보관 상태가 유지된다
12. [ ] 전체 백업 → (새 세션) 복원 후 매수/손절 연결까지 유지된다
13. [ ] 구버전(v1, 매수 연결 없는) 백업 JSON 복원이 거부되지 않고 읽힌다.
       반대로 매수 연결 포함 백업을 구버전 코드에 넣으면 거부된다는 점만
       메모로 남긴다. 구버전 화면 재구동은 하지 않는다
