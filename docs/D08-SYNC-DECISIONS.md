# D08 동기화 결정 기록

- 작성일: 2026-10-11 (사용자 결정)
- 상태: 결정 3건 확정. 구현·연동은 미착수이며 아래 결정만으로 클라우드·인증·동기화를 활성화하지 않는다.

## 확정 결정

1. 클라우드 DB: Supabase (원하는 설정·명령 전달용)
2. 로그인: Supabase Auth
3. 명령 수신 경로: Windows 엔진의 주기적 폴링

## 결정의 의미와 한계

- 위 3건은 제품 선택 결정이며, 프로젝트 URL·anon key·service key 등 비밀값은
  저장소에 기록·커밋하지 않는다. `.env`·토큰·운영 DB를 문서에 복사하지 않는다.
- 폴링 주기·충돌 해결·오프라인 복구·명령 서명/검증 방식은 미정이다. 정해지기
  전에는 D01 desired/accepted/applied 적용 연결을 구현하지 않는다.
- Supabase Auth와 계좌/환경 권한 매핑, RLS 정책, 감사 로그 보존은 후속 결정이
  필요하다. 정해지지 않은 값을 코드 기본값으로 만들지 않는다.
- 실제/모의 주문 API 호출, 운영 DB 변경, 배포는 별도 명시적 지시 없이 수행하지
  않는다.
