# D02 모바일 실기기 인수 체크리스트

갱신: 2026-10-22. 대상: 실제 iOS Safari + Android Chrome 각각 6/6.
이 문서는 검사 절차이며 **현재 두 기기 모두 NOT_RUN**이다.
기존 2026-10-11 문서의 “매수 연결 UI 없음”과 고정 과거 SHA를 현행 보드에 맞춰 수정했다.
PC 창폭·에뮬레이션 결과는 실기기 PASS로 기록하지 않는다.

## 준비와 기록

검사한 실제 커밋 SHA와 URL을 기록한다. `file://`을 사용하지 않고 승인된 테스트
URL 또는 같은 망 검증 PC가 **web 디렉터리만** 서빙하는 주소로 접속한다.
휴대폰 localhost는 PC에 접속하지 않는다. 새 Origin에는 PC 초안이 공유되지
않으므로 합성 종목·패턴을 새로 등록하거나 합성 백업을 사용한다.
원본 초안은 먼저 백업하고 저장소·환경파일을 공개 서빙하지 않는다.
PC 접속/서빙 절차는 [인계 패키지](api/BOARD-API-HANDOFF.md)의 모바일 항목을 참조한다.

| 기록 | iOS Safari | Android Chrome |
|---|---|---|
| 기종 | 미기입 | 미기입 |
| OS/브라우저 버전 | 미기입 | 미기입 |
| 실제 커밋 SHA | 미기입 | 미기입 |
| 접속 URL | 미기입 | 미기입 |
| 확인자·KST 시각 | 미기입 | 미기입 |

## 6개 인수 항목

| 번호 | 실제 조작·기대 결과 | iOS | Android |
|---|---|---|---|
| 1 | 종목 등록·검색·보관·복원 후 목록/건수 일치, 새로고침 후 유지 | NOT_RUN | NOT_RUN |
| 2 | 상세·설정 패널 터치로 열기/닫기, 스크롤·키보드 입력·정보 수정, 닫기 후 카드로 복귀 | NOT_RUN | NOT_RUN |
| 3 | 매수·손절 패턴 독립 연결/해제. 서로 다른 종류가 선택지에 섞이지 않음. 저장·새로고침 후 연결 이름·버전 유지. 비활성 패턴 새 연결 차단 | NOT_RUN | NOT_RUN |
| 4 | 매수 목표가 100001 거부, 양수 정상값 저장. 가상 가격 미리보기의 충족/미충족, 평균가 없는 비율 손절 보류와 주문 없음 안내 확인 | NOT_RUN | NOT_RUN |
| 5 | 전체 JSON 백업을 실제 기기에서 내려받아 다시 선택·복원, 매수/손절 연결·보관 유지. 기존 v1 백업도 복원 | NOT_RUN | NOT_RUN |
| 6 | 실제 기기 화면폭·회전·키보드 열린 상태에서 카드·패널·문구 잘림/가로 넘침 없음. 토글/버튼 터치와 초안·미조회 문구 가독성 확인 | NOT_RUN | NOT_RUN |

키보드 Esc 확인은 키보드가 연결된 경우 보조 검사이며 터치 닫기 검사를 대신하지 않는다.
항목별 PASS/FAIL, 실패 재현 단계와 민감값을 제거한 화면 근거를 기록한다.
파일 다운로드·선택을 지원하지 않는 접근 환경이면 5번은 미통과이며 PASS로 바꾸지 않는다.

## 판정과 후속

- 각 기기 6/6 PASS 및 기기/버전/커밋/시각 기록이 있어야 해당 기기 인수 통과다.
- FAIL/NOT_RUN이 하나라도 있으면 그 기기는 미완료다. 수정 후 같은 절차로 재확인한다.
- 결과는 `docs/D02-BOARD-PROGRESS.md`에 날짜 섹션으로 추가한다.
- 두 기기 인수 통과도 보드 서버 저장·D01/D08 인증/동기화·R04/R05 완료를 의미하지 않는다.

```markdown
- Android 기종/OS/Chrome/확인자/KST:
- iOS 항목 1~6: NOT_RUN, NOT_RUN, NOT_RUN, NOT_RUN, NOT_RUN, NOT_RUN
- Android 항목 1~6: NOT_RUN, NOT_RUN, NOT_RUN, NOT_RUN, NOT_RUN, NOT_RUN
- 실패 재현/근거 위치:
- 판정: 미완료 (실제 결과 기록 후 판정)
```
