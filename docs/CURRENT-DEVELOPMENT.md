## 사용 가능한 기능

- 통합 대시보드 7개 메뉴, 종목 검색, 키움 모의 최근 체결가 조회, 금액 계산, 로컬 초안과 보드 PIN 기반 서버 예약 등록·수정·취소를 제공한다. 계좌 조회는 별도의 열람 키로 보호한다.
- Supabase pg_cron이 매분 서버 예약의 KST 실행 시각을 확인한다. 검증된 2026년 KRX 영업일에만 DRY_RUN 결과를 기록한다. 지연 허용 범위는 지정 시각부터 2분 미만이다. 허용 구간이 지난 건과 도입 전 이미 만료된 건은 처리하지 않는다.
- 실행기 트랜잭션 잠금과 예약별 결과 기본 키가 중복 처리를 막는다. 중단 시 미커밋 처리는 롤백되고 다음 검사에서 유효한 예약을 다시 읽는다. 검증 오류는 예약별 오류 코드로, 작업 자체의 실패는 cron 작업 이력에 남는다.
- 주문·예약 화면에 대기, 시각 도달, 모의 검증 완료, 만료, 취소, 오류를 표시한다. 예정 시각과 실제 처리 시각은 각각 KST로 표시하며 열린 예약 화면은 15초마다 갱신한다.
- 실행 결과는 전용 DB 테이블에 보관한다. 실행 경로는 DB 내부 SQL만 호출한다. 키움 실주문, 모의주문, 자동매매는 모두 OFF다.

## 검증과 배포

- Node 테스트 71건. 독립된 PC·모바일 크기의 테스트 브라우저에서 고정 테스트 PIN으로 예약 등록·수정·취소 및 새로고침을 확인했다.
- PR CI의 reservation-dry-run 작업은 빈 PostgreSQL 17에 스키마를 적용하고 지정 시각 경계, 별도 연결 간 잠금, 트랜잭션 중단 후 복구, 재처리 방지, 휴장일·취소·만료 및 오류 결과를 검증한다. 격리 DB의 PIN 검사는 실패 5회 잠금, 잠금 해제, 세션 폐기를 포함한다.
- 세션은 12시간 유효한 Secure·HttpOnly·SameSite=Strict 쿠키로 관리한다. 서버는 변경 요청의 JSON 형식과 브라우저 출처를 확인한다. 공개 예약 조회는 HTTP 401이다.
- 고정 주소 https://cherryplus-ui-preview.vercel.app/#orders · Vercel 배포 dpl_hh7GHtbER11nibXuT8g8asXxAgv1. 원격 Supabase에 실행 기록 스키마와 매분 실행 일정을 적용했다. 최신 커밋 CI 결과는 PR #33에서 확인한다.

## 사용자 확인 및 미완료

- 고정 주소에서 확인한 브라우저에는 개인 로그인 세션이 없었다. 개인 PIN으로 로그인한 실제 PC·휴대폰에서 등록·수정·취소 및 결과 공유를 확인해야 한다. 테스트 브라우저 검증과 구별한다.
- 고정 미리보기의 계좌 조회는 서버 열람 키 설정 대기(HTTP 503) 상태다. 2027년 이후 거래일은 달력을 검증해 반영하기 전까지 차단한다.
- 다음 개발 범위는 키움 REST 모의주문 접수와 체결 확인이다. 이번 DRY_RUN은 증권사 접수·체결 기록을 만들지 않는다.
