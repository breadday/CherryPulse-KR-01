# CherryPlus 현재 개발

2026-11-24 기준 목표는 키움 국내주식 REST 중심 통합 대시보드 UI 완성이다. 현재 브랜치는 design/unified-trading-dashboard-20261121이며 시작 커밋은 7e0ac4c이다. 현재 UI 기준 커밋은 이 문서와 함께 기록되며 git log -1 -- web/dashboard.js 로 확인한다. 과거 전환 문서의 미완료 항목은 이번 범위에 추가하지 않는다.

## 화면과 연동

- 통합 홈, 관심종목·패턴 보드, 계좌·보유종목, 주문·예약, 주문·체결, 자동매매, 운영·설정으로 이동한다. URL 해시로 새로고침과 뒤로가기를 지원한다.
- 기존 종목 목록 3,488행에서 검색하고 키움 모의 REST 최근 체결가와 시각을 조회한다. web/market-data.js가 대시보드의 목록·시세 읽기 인터페이스다. 전체 상장시장 실시간 동기화는 미구현이다.
- 지정가 계산, 예수금·예비금 직접 입력, 시장가 금액 미확정, KST 예약 미리보기, 브라우저 초안 확인·수정·취소를 지원한다. 2026년 이후 거래소 일정은 미등록이다.
- 계좌·잔고·체결·전략 실행 기록은 미연결이다. 계좌 미조회 상태는 대시로 표시한다. 전략과 주문 실행은 OFF다. 즉시 주문은 입력 확인까지만 가능하다.

## 검증과 인계

- Node 자동 테스트 64건 통과. Chrome 1440px·390px에서 메뉴 7개, 가로 넘침, 새로고침, 70,000원 × 3주 매수 후 300,000원에서 90,000원 잔액, 예약 초안 생성·수정·취소, 시장가·즉시 모드를 점검했다. 브라우저 계산 검증에는 고정 시세 응답을 사용했다.
- 미리보기 전용 Vercel 배포 dpl_CakyyRfnDodkLxwk42e6FrgtGc3s 를 https://cherryplus-ui-preview.vercel.app/ 에 연결했다. 고정 주소에서 새 스크립트와 005930 모의 최근 체결 응답을 확인했다.
- 다음 우선순위는 읽기 전용 계좌·보유종목 응답을 연결해 예수금 0원과 미조회 표시, 보유종목 선택에서 주문 입력으로의 이동을 검증하는 것이다. 이후 주문·체결 상태별 조회와 전략 실행 기록을 연결한다. 예약 초안은 자동 실행하지 않는다.
- CI 결과는 이 브랜치 PR의 REST migration verification에서 확인한다. 자동 병합하지 않는다.
