## 목적

`REBUILD-02-OPEN-QUESTIONS.md`의 Q12(첫 매수/매도 패턴의 수치·시간 단위·재발동·재진입·미체결 정책)를 활성화 전 결정해야 할 항목으로 정리하고, 이번 단계에서는 **조건 평가의 기계적 규칙만** 구현한다. 특정 투자 기준값(어떤 가격, 몇 %, 몇 분봉)은 사용자 명시 승인 전까지 하드코딩하지 않는다.

## 패턴 평가 함수 규격

### 가격 돌파 조건 (PRICE_THRESHOLD)

- 입력: `observed_price`, `comparison`, `threshold_price` (모두 명시적 십진 문자열)
- `comparison=GTE`: 관측가 ≥ 기준가일 때만 충족
- `comparison=LTE`: 관측가 ≤ 기준가일 때만 충족
- 입력은 양수 정규 십진 문자열이어야 하며 아니라면 `PATTERN_PRICE_MUST_BE_POSITIVE`로 거절한다.
- 결과는 구조 없이 bool 반환, 주문 명령을 만들지 않는다.

### 평균 체결가 대비 비율 조건 (AVERAGE_PRICE_PERCENT)

- 입력: `average_price`, `percent` (음수, −100보다 크고 0보다 작음), `current_price`
- 계산 결과(청산 기준가격): `average_price × (1 + percent/100)`를 Decimal로 계산해 현재가와 비교한다.
- 현재가가 계산된 기준가격 이하이면 bool `True`를 반환한다.
- 평균가와 현재가의 양수 조건은 기존 `contracts.models`와 동일 스킴으로 검증한다.

## 활성화(실제 매수/매도 패턴 연결)의 선행 조건

아래 항목이 승인되기 전에는 패턴을 실제 감시 요청으로 활성화하지 않는다.

| 항목 | 설명 |
|---|---|
| 수치 | 돌파·손절 기준값(예: 몇 % 돌파, 몇 % 손절) |
| 시간 단위 | 체크하는 시간봉 또는 틱 즉시 |
| 재발동 | 한 번 발동 후 같은 조건에 다시 발동할지 여부 |
| 재진입 | 청산 후 같은 종목에 다시 진입할지 여부 |
| 미체결 정책 | 무응답 주문을 실측으로 어떻게 정리할지 |

승인이 없으면 패턴 평가 모듈을 어댑터·실제 주문에 연결하지 않는다.

## 현재 단계 제한

- 어댑터 또는 가상 dispatcher와 연결하지 않는다.
- 실제 증권사 API, 모의계좌 주문을 호출하지 않는다.
- 사용자 패턴의 기복값이 승인될 때까지 '샘플 패턴'으로 활성화하지 않는다.
