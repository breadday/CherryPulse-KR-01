# 아스트라 작업 지시서 — 예약 모의주문 실기기 검증

- 대상은 CherryPulse-KR-01 PR #33이다. 시작 전에 최신 커밋과 [개발 기록](CURRENT-DEVELOPMENT.md)을 확인한다.
- 기준 기록은 `7e33204`다. 운영 원장 적용 후 기존 예약 8건과 실행 기록 5건이 보존됐고, 휴대폰 카드 8건이 DB와 일치했다. 당시 신규 원장은 0건이었다.

## 이번 작업

1. 등록 휴대폰에서 확인할 별도 모의 지정가 테스트 예약 1건의 종목, 방향, 수량, 가격, 예정 시각을 제시한다. 사용자가 해당 조건과 전송을 명시적으로 승인하면 예약 시각 근처에 기존 화면의 사전확인과 최종 확인 절차로 키움 모의계좌에 한 번만 전송한다. 승인 전에는 조회와 준비만 진행한다.
2. 예약 ID로 원장 기록이 1건인지 확인하고, 키움 주문번호·주문 상태·체결 수량·잔량을 휴대폰 카드와 키움 모의계좌 조회 결과에서 대조한다. 미체결이어도 값이 일치하면 접수·조회 검증을 통과로 기록한다. 실제 체결 대조는 체결이 관찰된 경우에만 기록한다.
3. 접수 여부가 불명확하면 재전송을 차단하고 주문내역을 읽기 전용으로 대조한다. 여러 후보가 있으면 사용자가 주문을 식별할 때까지 미확인 상태로 둔다. 기존 DRY_RUN 카드와 모의주문 상태가 화면에서 구분되는지 확인한다.
4. 결과를 `docs/CURRENT-DEVELOPMENT.md`에 날짜와 KST 시각, 전송 횟수, 대조 결과, 미확인 항목과 함께 남긴다. 인증정보와 계좌 식별 정보는 문서에서 제외한다. 커밋 SHA와 푸시·CI·Vercel 상태를 보고한다. PR 브랜치 푸시는 Vercel 자동 배포를 유발할 수 있으므로 푸시 전에 확인한다.

완료 기준은 승인된 모의주문 1건의 원장·키움·휴대폰 일치와 결과 문서화다. 예약 시각 무인 전송은 이번 검증 이후의 개발 항목이다.
