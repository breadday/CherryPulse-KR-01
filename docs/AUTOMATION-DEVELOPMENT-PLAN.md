# 자동화 개발 계획

- 시작일: 2026-09-21
- 작업 브랜치: `feat/automated-rebuild-20260921`
- 기준 브랜치: `main`
- 원칙: 단계별 최소 구현, 자동검사, 독립 검토, 문서 기록, 원격 푸시

## 안전 경계

- 실계좌 주문과 실제 증권사 주문 API 호출은 자동 실행하지 않는다.
- 키움 OpenAPI+ 검증은 Windows 모의환경에서 먼저 수행하고 사용자가 결과를 확인한다.
- `.env`, 토큰, 계좌번호, 비밀번호와 운영 DB는 커밋하지 않는다.
- 불명확한 주문 결과를 자동 재전송하지 않는다.
- `main`에 직접 커밋하지 않고 기능 브랜치에 단계별로 푸시한다.

## 단계

### STEP 00 — 보안·개발 기준선

- 추적 중인 `.env` 제거와 `.env.example` 제공
- Windows/Linux 줄바꿈 정책 고정
- 자동화 범위와 검증 환경 기록

완료 조건: 비밀값이 신규 커밋에 포함되지 않고 작업 트리가 정상적으로 비교된다.

### STEP 01 — Vue 보드 기본 흐름

- `web/` Vue 3 + TypeScript 프로젝트
- 등록·설정, 매수 감시, 매수 주문 중, 보유·매도 감시, 매도 주문 중, 종료 보드
- 명시적인 mock 데이터와 모바일 레이아웃
- 단위 테스트와 빌드 검사

완료 조건: 종목 카드가 실행 상태에 따라 표시되고 mock임이 화면에 명확히 드러난다.

### STEP 02 — 공통 계약과 API 경계

현재 상태: 1차 구현과 자동검사 완료. [구현 기록](AUTOMATION-STEP-02-CONTRACTS.md)을 따른다.

- 종목, 패턴 버전, 실행 설정, 주문, 체결, 운영 상태 계약
- Python 모델과 TypeScript 타입의 대응
- 설정 요청/수락/거절/만료 상태
- 계약 fixture와 검증 테스트

완료 조건: 양쪽 모델이 같은 fixture를 읽고 잘못된 상태를 거절한다.

### STEP 03 — 손절 우선 실행 흐름

현재 상태: 구현과 자동검사 완료. [구현 기록](AUTOMATION-STEP-03-STOP-LOSS.md)을 따르며 독립 검토와 원격 푸시를 남겨 두었다.

- 부분 매수 체결 즉시 보호 의무 등록
- 손절 조건 평가와 청산 의무 생성
- 기존 예약·UNKNOWN·수량 불일치 시 중복 제출 차단
- Windows 전용 계좌 잠금 경계 유지

완료 조건: 가상 어댑터 시나리오가 통과하고 실계좌 호출은 존재하지 않는다.

### STEP 04 — 매수·일반 매도 패턴

- 버전이 있는 가격 조건 패턴
- 감시 시작 요청과 엔진 수락
- 중복 신호와 재발동 정책
- 부분체결 이후 보호 흐름 연결

### STEP 05 — 동기화와 실제 보드

현재 상태: 웹 동기화 상태 reducer와 오프라인·지연 표시 구현 및 자동검사 완료. [구현 기록](AUTOMATION-STEP-05-SYNC.md)을 따른다.

- 중복·역순 이벤트 처리
- 로컬 outbox와 웹 조회 상태 분리
- 오프라인 복구 및 지연 표시
- Vercel/관리형 DB 배포는 별도 승인 후 수행

### STEP 06 — 키움 모의환경 검증

현재 상태: 실제 키움 연결 전 안전한 로컬 paper harness와 조회 전용 경계를 구현·검증 완료. [구현 기록](AUTOMATION-STEP-06-PAPER.md)을 따른다.

- 조회 전용 연결
- 원문 이벤트 저장과 재생
- 모의계좌 주문/취소/부분체결 검증
- 사용자가 결과를 확인한 뒤 다음 단계 결정

### STEP 07 — 명령 동기화 경계

현재 상태: 외부 연결 전 로컬 명령 envelope와 버전·만료·중복·충돌 검증을 구현·검증 완료. [구현 기록](AUTOMATION-STEP-07-COMMAND-SYNC.md)을 따른다.

- 명령 envelope와 적용 버전 검사
- 만료·중복·충돌 명령 처리
- 외부 transport·인증은 별도 승인 후 수행

### STEP 08 — Windows 모의환경 어댑터

현재 상태: 실제 키움 연결 전 Windows/PAPER 선언, 조회 전용 quote, 결정적 ACK·REJECT·UNKNOWN·부분체결 경계를 구현·검증 완료했다. [구현 기록](AUTOMATION-STEP-08-WINDOWS-ADAPTER.md)을 따른다.

- Windows/PAPER 실행 경계
- 조회 전용 quote와 submit 관측
- UNKNOWN 자동 재전송 차단
- 실제 키움·계좌·네트워크 연결 없음
