예약 사용 (지정 PC에 작업이 등록·활성화된 경우)
- 작업 상태와 다음 실행을 먼저 확인하세요: `Get-ScheduledTask -TaskName "CherryPulse-R045-Demo" | Select-Object TaskName,State`
- 작업은 평일 09:30에 실행되며, 장중·인증·조회·시세 조건을 통과하면 기존 승인 범위의 모의 1주 지정가 주문을 한 번 시도할 수 있습니다.
- 콘솔 로그: `results\r045-morning-run.log`; 실행 날짜 폴더의 `manifest.json`에서 단계별 결과를 확인합니다.
저녁에 확인
1. HTS(영웅문)에서 미체결 주문 확인 → 안 체결됐으면 직접 취소
2. opencode에서 "r045 manifest 확인해" 한 마디 → 제가 증가 검토 → 체크리스트 양식으로 증거 문서화 → R04/R05 상태 갱신까지 마무리
수동 실행 (원할 때)
py -3.10 -m tools.r045_morning_run
- REST 프로브는 32/64비트 모두 가능합니다. 예약 작업도 `py -3.10` 인터프리터를 사용합니다.
- WebSocket 의존성은 같은 인터프리터에 한 번 설치합니다: `py -3.10 -m pip install -r tools/requirements-rest-probes.txt`
- 장 밖(09:00~15:20 제외)·주말이면 자동 SKIP(AFTER_CLOSE 등) — 안전하게 무시됩니다. 주문 1회는 오늘 날짜 센티널로 하루 1회만.
예약 작업 관리
Get-ScheduledTask -TaskName "CherryPulse-R045-Demo"          # 상태 조회
Unregister-ScheduledTask -TaskName "CherryPulse-R045-Demo" -Confirm:$false   # 삭제
