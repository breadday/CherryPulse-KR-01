## 실행 환경 및 키움 검사 도구

- 활성 기준은 64-bit Python 3.15 `.venv-rest`와 REST/HTTP·WebSocket이다.
- COM/ActiveX 전용 `verify_kiwoom_com.py`, `verify_kiwoom_connection.py`, `verify_kiwoom_readonly.py`, `tools/inspect_kiwoom_realtime.py`는 비활성화됐다. 실행 시 REST-only 안내를 출력하고 종료하며 네트워크·계좌·주문 호출은 하지 않는다.
- 대체 오프라인 점검은 `.venv-rest/Scripts/python.exe -m tools.probe_kiwoom_rest` 및 `.venv-rest/Scripts/python.exe -m tools.probe_kiwoom_ws`다. 실시간 조회를 포함한 실제 네트워크 실행은 `--execute-read-only` 명시와 별도 승인 없이는 하지 않는다.
- REST/WebSocket 도구는 과거 COM TR·로그인 상태와 일대일 동등하지 않다. COM control 생성 확인은 REST 대체 항목이 없다.
