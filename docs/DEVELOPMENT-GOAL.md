# CherryPulse-KR-01 개발 목표

- 작성일: 2026-09-24
- 근거: [남은 개발 작업 계획](NEXT-DEVELOPMENT-PLAN.md), [D03 진행 기록](D03-VIRTUAL-STOP-PROGRESS.md), 저장소 `AGENTS.md`
- 용도: 긴 개발 작업을 같은 대화에서 이어갈 때 목표·완료 조건·차단 조건을 한 번에 전달한다. 이 문서만으로 실행 권한이 생기지 않는다.

## 붙여 넣을 목표

> CherryPulse-KR-01 저장소의 `AGENTS.md`와 `docs/NEXT-DEVELOPMENT-PLAN.md`를 기준으로 D01~D10 개발을 의존 순서대로 계속 진행해 줘. 현재 코드와 미커밋 변경을 먼저 확인하고 보존해 줘. 각 단계에서 계약·코드·필요한 검사·결과 문서를 만들고, 검사 실패 시 원인을 수정해 다시 확인해 줘. 특히 부분 매수 체결 직후 보호, 중복 신호와 취소 `UNKNOWN`의 중복 매도 방지, 매도 부분체결, 재시작 대조, 주문 수량 보존을 가상 원장 시나리오로 검증해 줘. 문서 검산·Linux 가상 검사·Windows 전체 검사·키움 실증을 서로 구별해서 기록해 줘. 확인되지 않은 증권사 필드나 체결 가격을 추정하지 말고 미확인 상태로 남겨 줘. 실제/모의 계좌의 키움 주문 API 호출, 운영 DB 변경, 배포는 수행하지 마. 해당 단계에 도달하면 실행 가능한 코드와 검증 계획까지 준비하고, 필요한 PC 환경·사용자 결정·별도 승인을 구체적으로 알려 줘. `back/`의 기존 매매 전략을 활성 경로로 복원하지 말고, 커밋·푸시는 별도 요청을 받은 범위에서만 해 줘. 각 단계가 끝날 때 통과 근거와 미완료 사항을 확인하고, 다음에 안전하게 할 수 있는 작업이 있으면 계속 진행해 줘. 더 진행할 수 없는 명확한 차단 사항이 생기면 시도한 작업, 근거, 필요한 입력을 보고해 줘.

웹의 ChatGPT Work에서는 위 내용을 같은 대화에 일반 메시지로 붙여 넣는다. `/goal` 명령이 제공되는 앱 환경에서는 명령 뒤에 목표를 넣을 수 있다. 목표는 작업의 범위와 완료 기준이며 백그라운드 실행이나 무제한 접근을 보장하지 않는다.

## 완료를 판단하는 기준

1. D01~D05: 설정 적용과 패턴, 손절·보호 의무·가상 실행이 원장과 연결된다. 가격/비율 손절, 부분체결, 중복 이벤트, 취소 불확실성, 재시작, 기존 매도 예약에서 검증된 수량과 차단 사유가 남는다.
2. D02·D09: 사용자가 등록한 종목과 매수·매도 패턴을 보드에서 관리하며, 희망 설정과 Windows 엔진에 실제 적용된 설정을 화면에서 구분한다. 화면 조작 자체가 주문을 만들지 않는다.
3. D06~D08: 키움 읽기 전용 자료로 주문·체결 식별자와 조회 완전성을 실증하고, 권한 있는 설정 전달과 상태 동기화를 검증한다. 확인되지 않은 매핑은 격리하거나 실행을 차단한다.
4. D07·D10의 실제 주문·운영 인수·배포는 별도 명시적 지시와 지정 PC·계좌의 근거 확인 전까지 **준비 단계**로 기록한다. 여기까지 자동으로 완료 선언하지 않는다.
5. 각 완료 주장에는 변경 파일, 테스트 명령·결과, 재현 가능한 시나리오, 미실행 검사와 이유, 미해결 질문을 함께 적는다. 전체 검사와 실제 계좌 검증을 실행하지 못한 경우 그대로 표시한다.

## 현재 진행 기록 (2026-09-24)

- D03의 가상 판정과 추가 보호 후보는 고정 가격·원가 비율 규칙 모두 원장 근거와 연결했다. 기존 매도 예약·부분 매도·`UNKNOWN`·오래된 시세의 조회 전용 안전 경계를 검증했다.
- 고정 가격·확인된 원가 비율 손절의 발동 상태는 가상 원장에 한 번 기록하고 재시작·늦은 매수 체결 후에도 유지한다. 새 매수 진입은 차단한다. 별도 정규장 가상 dispatcher 호출이 남은 수량을 시장가 매도 요청으로 예약·전송한다. 실제 세션 확인이나 자동 시세 연결은 아직 없다.
- 사용자 확정 정책: 원가 불명 시 비율 손절 실행 차단, 시세 지연 최대 2초, 발동 상태 유지, 주문 제출은 정규장만.
- 남은 D03 완료 기준은 청산 의무와 매도 주문의 명시적 1:1 추적, 자동 시세 감시·검증된 세션 경계, 미체결·거절 정책이다. 보유 원가가 없는 기존 보유와 매도 뒤 비율 손절은 새로운 발동을 차단한다. 이미 발동한 보호는 유지한다.
- D01의 희망 설정 수락과 로컬 적용 간 원자적 경계, D02와 D04~D10도 아직 완료되지 않았다. Windows 3.10 32비트 및 키움 실증·실제 주문·배포를 완료로 기록하지 않는다.

## 중단하고 보고할 때

- 주문 활성화에 필요한 시세 지연 허용치, 거래 세션, 거절·미체결 대응, 기존 보유 원가/규칙 인계 정책에 근거가 없을 때는 불확실한 경로를 활성화하지 않는다. 결정 없이 가능한 가상 검증과 UI 골격은 계속 진행한다.
