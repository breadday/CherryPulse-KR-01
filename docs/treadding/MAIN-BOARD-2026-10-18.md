# 메인 보드 개발 확인

기준: main 24b6aaf. 종목·손절·매수 패턴 초안 화면은 이미 존재했다.
README 미구현 안내를 정정하고 web 루트 진입점, 현황 집계, 메뉴를 추가했다.

- 관심·보관, 손절 패턴 연결·미연결 수를 초안에서 집계한다.
- 없는 패턴 ID는 미연결로 처리한다. 검색·목록 필터는 전체 집계에 영향을 주지 않는다.
- 엔진 미연결·시세 미수신·계좌 미조회·주문 비활성을 명시한다.
- 보관·복원·입력 시 기존 render 흐름에서 현황을 갱신한다.
- 가격·보유·체결·감시 상태는 생성하지 않는다. 기존 저장 키를 유지한다.

검사: node --test web/board/board.test.js → 24 passed.
